Importez ces données réelles dans l'onglet Administration → Import / Export dès qu'elles seront disponibles.

Structure des usages (groupe → classe → sous-classe) telle qu'établie au document de référence. Cette classification est modifiable uniquement via Import / Export JSON (onglet Administration).
